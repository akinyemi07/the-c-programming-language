# K&R C Study Repository

A structured repository for studying and mastering the book:

> "The C Programming Language" by Brian W. Kernighan and Dennis M. Ritchie (2nd Edition)

This repository is designed not just for reading the book, but for:
- writing production-style C code,
- experimenting safely,
- understanding systems programming,
- practicing debugging,
- learning Git discipline,
- and building engineering habits.

---

# Goals of This Repository

This repository exists to help achieve the following:

- Learn the C language deeply
- Understand memory and pointers
- Practice problem solving
- Build debugging skills
- Learn compilation and linking
- Build project organization habits
- Learn reusable code design
- Prepare for systems programming
- Create mini projects while learning
- Develop strong Git workflows
